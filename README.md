# SpEl — Intelligent Digital Sheet Music

SpEl is an ongoing research and software development project exploring intelligent tools for digital sheet music.

The project aims to improve how musicians and musical institutions interact with digital scores, with a focus on document analysis, automation, and computer vision.

**Research areas:** Python, Computer Vision, Machine Learning, Digital Music Technology.

## Project Status

Active research and development. Technical details, implementation, and experimental results are currently confidential.
